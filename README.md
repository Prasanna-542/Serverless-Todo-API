# Serverless Todo API

Built a serverless CRUD REST API using AWS Lambda, API Gateway, and DynamoDB.

## Services Used
- AWS Lambda
- API Gateway
- DynamoDB
- IAM

## Features
- Create Todo
- Get Todos
- Update Todo
- Delete Todo

## Architecture

User -> API Gateway -> Lambda -> DynamoDB

## Learning Outcomes
- Serverless Architecture
- REST APIs
- IAM Roles
- DynamoDB Operations
